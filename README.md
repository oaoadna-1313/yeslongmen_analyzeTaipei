## 🎯 專案特色

1. **雙模式自由切換**：
   - 🎒 **學生視角**：純淨文本無標記、向度要點預設遮罩防劇透、雷達圖初始留白引導自主探索。
   - 👨‍🏫 **教師導引**：一鍵展開全文本關鍵高亮、向度要點全顯、五維度雷達全覽對照。
2. **四大名家文本深讀**：
   - 舒國治〈水渠、老樹與巷弄——浮世繪臺北〉（日常漫遊・市井煙火）
   - 韓良露〈這座城市的甜美與殘酷〉（冷冽反思・都市文明）
   - 劉克襄〈群山環抱的綠色秘境〉（自然生態・綠意脈動）
   - 張曼娟〈在每個尖峰時刻，遇見自己的影子〉（都會心靈・生命共振）
3. **多元科技與互動學習**：
   - 🎙️ **Web Speech API 語音朗讀**：四篇文本支援語音朗讀，搭配朗讀進度即時控制。
   - 📊 **五維度雷達圖動態比對 (Chart.js)**：提供全圖對照、極端對比、都市漫遊等多種分析模式。
   - 🧩 **跨文本綜合比較矩陣**：四大向度（感官描摹、歷史記憶、空間意象、文化反思）系統歸納。
   - ⚖️ **觀點思辨擂台**：情境探究題組，引導學生深入辯證各文本視角差異。
   - 📝 **學生思辨回饋卡**：線上填寫觀點結論，支援一鍵複製與列印學習成果。

## 🛠️ 技術架構

- **前端核心**：HTML5 / Vanilla JavaScript (ES6+)
- **排版樣式**：Tailwind CSS CDN
- **視覺圖表**：Chart.js CDN (Radar Chart)
- **圖示庫**：Lucide Icons CDN
- **字型資源**：Google Fonts (`Noto Serif TC`, `Noto Sans TC`, `Ma Shan Zheng`)
- **語音合成**：HTML5 Web Speech API (`speechSynthesis`)
